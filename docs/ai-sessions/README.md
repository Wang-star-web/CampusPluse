# AI 对话快照存档

**Vibe Coding 赛道的命门交付物：AI 对话历史导出。**

## 每天收工前做一件事

把当天与 AI 工具（Cursor / Trae / WorkBuddy）的开发对话导出为 md，命名为 `YYYY-MM-DD.md` 放进本目录，**和当天的 commit 同一天完成**。

## 什么必须留

- 需求描述（你怎么把想法说给 AI 听）
- AI 写错的地方 + 你的纠正（**这类对话最值钱**）
- 架构决策的讨论过程

## 什么不能做

- 补写、美化、事后编造快照——评委会抽查快照时间戳和 commit 时间对不对得上
- 把 AI 输出原样贴进代码却读不懂（答辩/评审会被问）

## 关键节点单独标注

架构定型、大 Bug 修复、重构这三次，在 README 里指路到具体快照文件。

## 和最终交付物的关系（别搞混）

**本目录是每天的原始存档**（流水账，按天）。
**最终交给比赛的是另一份**：`02_AI对话快照/` 目录——从本目录的日常记录里挑 3 个"核心功能迭代"的案例，按 `05_VibeCoding参赛指导/02_AI对话快照模板.md` 的格式整理成举证包（提问→方案→问题→纠偏→验证）。

简单说：这里管"攒"，02_AI对话快照 管"交"。攒得越勤，交的时候越有得挑。
