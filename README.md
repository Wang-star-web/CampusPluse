# CampusPulse 校园活动脉搏

> 校园大型活动的「现场指挥舱」：900 人涌进来的时候，告诉组织者**现在到底怎么样**。

不是"又一个看板"——它回答的是：入口人数正常吗？下雨了要不要改路线？支持人员够不够？

## 快速开始（3 分钟）

```bash
pip install -r requirements.txt
# 下载失败换镜像：pip install -i https://mirrors.aliyun.com/pypi/simple/ -r requirements.txt
cd backend && uvicorn main:app --reload --port 8000
# 浏览器打开 http://localhost:8000
```

## 核心设计原则（本作品的灵魂）

**态势由显式规则计算，LLM 只解释、不判定。**
看板上的"整体正常 / 态势偏高 / 存在受阻"来自可追溯的规则与证据，不是大模型临时总结的一句话。开发时 AI 工具大概率会顺手把态势总结写成 LLM 生成——**请纠正它，并把这段纠正对话留进快照**（这是意图控制的满分素材）。
